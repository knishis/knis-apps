よくある質問

ファイルアプリで開きたいファイルが選べません(グレーアウトしている)
KnisEdit はテキスト系のファイルに加えて、任意のファイルも開けるように登録しています。それでも選べない場合は、そのファイルを長押しして「共有」から KnisEdit を選ぶか、ファイルアプリで KnisEdit のフォルダへコピーしてから開いてください。
日本語が文字化けします
文字コードは UTF-8(BOM の有無)、Shift_JIS、EUC-JP、JIS(ISO-2022-JP)、UTF-16 を自動判定しています。判定結果は画面下部のステータス表示で確認できます。短いファイルなど判定が難しい場合は正しく判定できないことがあります。保存時は開いたときの文字コードを維持します。
シンタックスハイライトが効きません
言語は拡張子から判定します。拡張子が無いファイルや、クラウドストレージ経由で拡張子の情報が得られない場合は、中身から推測するか、右上の「…」メニューの「言語モード」で手動で切り替えてください。対応言語は Swift / Python / JavaScript / TypeScript / C / C++ / C# / Java / Go / Rust / Ruby / PHP / Perl / Lua / HTML / CSS / SCSS / Markdown / JSON / YAML / TOML / SQL / Bash など 24 言語です。
grep はどこを検索しますか
「…」メニューの「grep」でフォルダを選ぶと、そのフォルダ以下のテキストファイルを横断して検索します。Shift_JIS など UTF-8 以外のファイルも対象です。結果の行をタップするとその場で開いて編集できます。
フォントサイズや配色を変えたい
「…」メニューの「テーマ設定」でプリセットの切り替え、背景色・文字色の上書き、フォントサイズの変更ができます。エディタ上のピンチ操作でもフォントサイズを変えられます。
データはどこかに送信されますか
いいえ。本アプリは利用者が開いたファイルを読み書きするだけで、開発者や第三者のサーバーへは一切送信しません。詳しくは プライバシーポリシー をご覧ください。

FAQ

Japanese text looks garbled
KnisEdit detects UTF-8 (with or without BOM), Shift_JIS, EUC-JP, ISO-2022-JP and UTF-16 automatically and shows the result in the status area. Very short files may be misdetected. Files are saved in the encoding they were opened with.
Syntax highlighting does not work
The language is chosen from the file extension. If the extension is missing or unavailable, use "Language mode" in the "…" menu to pick it manually.
Is any data sent anywhere?
No. The app only reads and writes the files you open. Nothing is sent to the developer or any third party. See the Privacy Policy.
