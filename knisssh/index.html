よくある質問

接続できません
接続先と同じネットワーク(または VPN)に入っているか、接続先で SSH サーバーが動いているか(通常 22 番)をご確認ください。 初回接続時に表示される「ローカルネットワーク上のデバイスの検索と接続」の許可が必要です。拒否した場合は「設定 › プライバシーとセキュリティ › ローカルネットワーク」から KnisSSH を有効にしてください。
秘密鍵が読み込めません / 未対応の鍵形式です
OpenSSH 形式(-----BEGIN OPENSSH PRIVATE KEY-----)の ed25519 / RSA 鍵に対応しています。ECDSA 鍵と PuTTY 形式(.ppk)には対応していません。 PEM 形式の鍵は ssh-keygen -p -f 鍵ファイル -m RFC4716 で変換してください。アプリ内で鍵ペアを生成して公開鍵を接続先に登録する方法もあります。
「ホスト鍵が変わっています」と出ました
接続先のサーバーを再インストールした場合などに出ます。心当たりが無ければ「中止」を選び、接続先の管理者に確認してください。記憶したホスト鍵は 設定 › ホスト鍵 で削除できます。
他のアプリに切り替えると切断されます
iOS の制約で、バックグラウンドでは接続を維持できません。長時間かかる処理は接続先で tmux や screen を使ってから実行してください。
パスワードや鍵はどこに保存されますか
端末内の iOS キーチェーンにのみ保存され、外部には送信されません。詳しくは プライバシーポリシー をご覧ください。

FAQ

I can't connect
Make sure your device is on the same network (or VPN) as the host and that an SSH server is running there (usually port 22). KnisSSH needs the Local Network permission; enable it in Settings › Privacy & Security › Local Network if you declined the prompt.
Which key formats are supported?
OpenSSH-format ed25519 and RSA private keys. ECDSA keys and PuTTY (.ppk) files are not supported. You can also generate an ed25519 key pair inside the app.
Where are my passwords and keys stored?
Only in the iOS Keychain on your device. They are never sent to the developer or any third party. See the Privacy Policy.
