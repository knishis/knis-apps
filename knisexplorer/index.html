KnisExplorer サポート

iOS / iPadOS 向け 2 ペイン ファイルマネージャー(SFTP・SMB・写真ライブラリ・Files アプリ)

お問い合わせ

不具合の報告・ご質問・ご要望は knishis.dev@gmail.com までお送りください。 ご利用の機種、OS バージョン、接続先の種類(SFTP なら SSH サーバーの OS、SMB なら Windows か NAS か)を添えていただくと調査がスムーズです。

使い方
操作マニュアルはアプリ内に入っています。画面下の「F1 ヘルプ」から開いてください。

よくある質問

SFTP に接続できません
接続先 PC と同じネットワーク(または VPN)に入っているか、接続先で SSH サーバーが動いているか(通常 22 番)をご確認ください。 初回接続時に表示される「ローカルネットワーク上のデバイスの検索と接続」の許可が必要です。拒否した場合は「設定 › プライバシーとセキュリティ › ローカルネットワーク」から KnisExplorer を有効にしてください。
秘密鍵が読み込めません
OpenSSH 形式(-----BEGIN OPENSSH PRIVATE KEY-----)の ed25519 / RSA 鍵に対応しています。PEM 形式の鍵は ssh-keygen -p -f 鍵ファイル -m RFC4716 で変換してください。アプリ内で鍵を生成して公開鍵を接続先に登録する方法もあります。
「ホスト鍵が変わっています」と出ました
接続先のサーバーを再インストールした場合などに出ます。心当たりが無ければ「中止」を選び、接続先の管理者に確認してください。
写真が表示されません
「設定 › KnisExplorer › 写真」で「フルアクセス」を選んでください。「制限付きアクセス」では選んだ写真だけが表示されます。
パスワードや鍵はどこに保存されますか
端末内の iOS キーチェーンにのみ保存され、外部には送信されません。詳しくは プライバシーポリシー をご覧ください。

FAQ

I can't connect over SFTP
Make sure your device is on the same network (or VPN) as the host and that an SSH server is running there (usually port 22). KnisExplorer needs the Local Network permission; enable it in Settings › Privacy & Security › Local Network if you declined the prompt.
Where are my passwords and keys stored?
Only in the iOS Keychain on your device. They are never sent to the developer or any third party. See the Privacy Policy.
