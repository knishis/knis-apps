よくある質問

ブックを本棚に入れるには
本棚の「+」から Files アプリのフォルダや zip(cbz)を選びます。コピーせず参照だけを登録します。 Files アプリの「KnisViewer › Books」にフォルダや zip を置くと、起動時に自動で登録されます。 「ライブラリフォルダを追加」で親フォルダを選ぶと、中の zip / 画像フォルダがそれぞれ 1 冊として並びます。
本棚のブックが「見つかりません」になります
参照登録なので、元のフォルダや zip を Files アプリで移動・削除すると開けなくなります。元に戻すか、登録し直してください。
SFTP サーバーに接続できません
接続先と同じネットワーク(または VPN)に入っているか、SSH サーバーが動いているかをご確認ください。 初回接続時に表示される「ローカルネットワーク上のデバイスの検索と接続」の許可が必要です。拒否した場合は「設定 › プライバシーとセキュリティ › ローカルネットワーク」から KnisViewer を有効にしてください。
Dropbox / OneDrive に接続するには
ご自身で Dropbox App Console(App key)または Microsoft Entra(クライアント ID)にアプリを登録し、そのキーを接続先の編集画面に入力してからサインインします。アプリにはキーは組み込まれていません。
シークレットにしたブックが見つかりません
本棚の並び順メニュー(↕)の「シークレットを表示…」または設定の「シークレット」から、Face ID / パスコードで確認すると表示されます。 バックグラウンドに回ると設定の秒数で自動的に隠れます。
キャッシュが端末の容量を使っています
設定の「キャッシュ」でサムネイルとリモートページのキャッシュを削除できます。本棚のリモートブックは長押し →「キャッシュを削除」でも消せます。
パスワードや鍵はどこに保存されますか
端末内の iOS キーチェーンにのみ保存され、外部には送信されません。詳しくは プライバシーポリシー をご覧ください。

FAQ

How do I add books?
Tap "+" on the shelf and pick a folder or a zip / cbz in the Files app; the app keeps a reference and does not copy the files. Anything placed in "KnisViewer › Books" in the Files app is registered automatically at launch. "Add library folder" registers every zip / image folder inside a parent folder as a separate book.
A book shows "not found"
Books are references, so moving or deleting the original folder or archive in the Files app breaks them. Put it back or register it again.
I can't connect to my SFTP server
Make sure your device is on the same network (or VPN) as the host and that the SSH server is running. KnisViewer needs the Local Network permission; enable it in Settings › Privacy & Security › Local Network if you declined the prompt.
Dropbox / OneDrive
Register your own app in the Dropbox App Console (app key) or Microsoft Entra (client ID), enter the key in the connection editor, then sign in. No key is embedded in the app.
Where are my passwords and keys stored?
Only in the iOS Keychain on your device. They are never sent to the developer or any third party. See the Privacy Policy.
