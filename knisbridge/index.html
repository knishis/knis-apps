KnisBridge サポート

自分の端末どうし(Windows PC / iPhone / iPad / Android)をつなぐ個人用ブリッジ。通知・共有ボード・ファイルを登録済みの端末間でやり取りします。

入手
KnisBridge は開発者とその周囲の端末のために作られた個人用アプリで、App Store では非公開配信(検索に出ません)です。 利用には管理者が発行する登録コードが必要で、コードを持たない方はアプリを入手しても登録できません。

お問い合わせ

不具合の報告・ご質問は knishis.dev@gmail.com までお送りください。 ご利用の機種、OS バージョン、起きた操作(登録 / ボード / 通知 / ファイル)を添えていただくと調査がスムーズです。

よくある質問

登録できません
登録コードは 1 回限りで、有効期限があります。期限切れや入力済みのコードは使えませんので、管理者に再発行を依頼してください。 サーバー URL は https:// から始まるアドレスをそのまま入力します。
通知が届きません
初回起動時の通知の許可が必要です。拒否した場合は「設定 › 通知 › KnisBridge」から許可してください。 アプリを開いているときは画面内に、閉じているときはプッシュ通知として届きます。
端末一覧に相手が出ません
相手の端末がまだ登録されていないか、登録を解除しています。同じサーバーに登録された端末だけが一覧に並びます。
登録を解除したい
設定タブの「登録解除」で、この端末の登録とプッシュ通知の登録をサーバーから削除します。アプリを削除するだけでも端末内の情報は消えます。
データはどこに保存されますか
ボードの投稿と送ったファイルは、開発者が管理するサーバー(Microsoft Azure、日本リージョン)に保存され、登録済みの端末だけが読めます。 詳しくは プライバシーポリシー をご覧ください。

KnisBridge Support

A personal bridge between your own devices (Windows PC / iPhone / iPad / Android): notifications, a shared board and files between enrolled devices.

Availability
KnisBridge is a personal app made for the developer's own devices and is distributed unlisted on the App Store. Enrolling a device requires a one-time code issued by the administrator; without a code the app cannot be used.

Contact

For bug reports or questions, email knishis.dev@gmail.com. Please include your device model, OS version and what you were doing (enroll / board / notification / files).

FAQ

I cannot enroll
Enrollment codes work once and expire. Ask the administrator for a new code. Enter the server URL exactly as given, starting with https://.
Notifications do not arrive
Allow notifications when asked at first launch, or enable them later in Settings › Notifications › KnisBridge. While the app is open, items appear in the app; otherwise they arrive as push notifications.
Where is my data stored?
Board posts and files you send are stored on a server operated by the developer (Microsoft Azure, Japan region) and are readable only by enrolled devices. See the Privacy Policy.
