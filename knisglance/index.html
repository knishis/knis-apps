よくある質問

ニュースが出ません
KnisGlance は、利用者自身が動かしているニュース収集サーバー(KnisNewsCollector)からニュースのまとめを取得します。アプリにニュースの配信元は組み込まれていません。 サーバーが無い場合は、設定の「サンプルのニュースを表示する」で、アプリに入っている架空のニュースを使って動きを試せます。
サーバーに接続できません
サーバーと同じネットワーク(または VPN)に入っているか、設定の「ニュースサーバー」の URL が正しいかをご確認ください。 初回に表示される「ローカルネットワーク上のデバイスの検索と接続」の許可が必要です。拒否した場合は「設定 › プライバシーとセキュリティ › ローカルネットワーク」から KnisGlance を有効にしてください。 接続できないときは、前回取得した分を表示します。
読み上げの声を変えたい
サーバーが音声(VOICEVOX)を用意している場合はその音声で、無い場合は端末の声で読み上げます。端末の声は、iOS の「設定 › アクセシビリティ › 読み上げコンテンツ › 声 › 日本語」で拡張・プレミアム版を入れると聞き取りやすくなります。
操作の一覧
タップ = タイルを選ぶ / ダブルタップ = 拡大・分割に戻る / 拡大中に下へスワイプ = 分割に戻る / 拡大中に左右へスワイプ = 次・前のニュース / 分割中に左右へスワイプ = 次・前のグループ。

FAQ

No news is shown
KnisGlance fetches news digests from a news-collector server (KnisNewsCollector) that you run yourself. No news source is built into the app. Without a server, turn on "Show sample news" (サンプルのニュースを表示する) in Settings to try the app with fictional sample news bundled in the app.
I can't connect to my server
Make sure your device is on the same network (or VPN) as the server and that the server URL in Settings is correct. KnisGlance needs the Local Network permission; enable it in Settings › Privacy & Security › Local Network if you declined the prompt. When the server cannot be reached, the app shows the digests it fetched last time.
Narration voice
If your server provides audio (VOICEVOX), the app plays it; otherwise it reads with the device's built-in voice.
