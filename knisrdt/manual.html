KnisRDT 操作マニュアル

iPhone / iPad から Windows や Linux、Mac のデスクトップを操作するリモートデスクトップクライアントです。RDP と VNC の 2 つの方式に対応しています。

  • RDP: Windows 標準のリモートデスクトップ。Windows Pro 以上のエディションでリモートデスクトップを有効にすると使えます。クリップボード共有と音声の転送に対応しています。
  • VNC: Windows Home、Linux、Mac(画面共有)など、VNC サーバーが動いている機器に接続します。

1. はじめに

接続先の準備

接続先準備既定のポート
Windows Pro / Enterprise設定 → システム → リモートデスクトップ を ON3389(RDP)
Windows HomeRDP サーバー機能が無いため、TightVNC などの VNC サーバーを導入5900(VNC)
Macシステム設定 → 一般 → 共有 → 画面共有 を ON、「VNC 使用者が画面を操作することを許可」でパスワードを設定5900(VNC)
Linuxx11vnc、TigerVNC など任意の VNC サーバー5900(VNC)

iPhone / iPad は接続先と同じ Wi-Fi(LAN)にいるか、VPN で接続先のネットワークに入っている必要があります。

初回起動時の許可

最初に接続すると「ローカルネットワーク上のデバイスの検索と接続」の許可を求められます。許可 してください。誤って拒否した場合は、iOS の 設定 → プライバシーとセキュリティ → ローカルネットワーク で KnisRDT を ON にします。

起動すると登録済みの接続先が一覧で表示されます。各行には表示名と、方式・ホスト名・ポートが出ます。

操作動作

行を右へスワイプ編集

接続先を削除すると、保存されていたパスワードも端末から消えます。

3. 接続先の追加・編集

接続先

項目内容

ホスト名 / IP接続先のコンピューター名または IP アドレス(必須)
プロトコルRDP または VNC
ポート空欄なら既定値(RDP は 3389、VNC は 5900)を使います

認証

項目内容
ユーザー名接続先のログオン名(RDP で使用)
パスワード接続先のパスワード。端末の iOS キーチェーンにのみ保存され、外部には送信されません。空欄で保存すると削除されます

解像度(RDP のみ)

接続先のデスクトップを何ピクセルで表示するかを決めます。

  • 横ピクセル: 1280 / 1440 / 1600 / 1920 / 2560 / 3840 のうち端末の画面より小さいもの、または「端末短(端末の短辺)」「端末長(端末の長辺)」から選びます。既定は 1280 です。
  • 縦横比: 「自動」にすると、接続したときの画面の向きに合わせて高さ(縦向きなら幅)を計算します。16:9 などを選ぶと固定の比率になります。

おすすめは「自動」です。 自動のとき、接続中に端末を回転させると、新しい向きに合わせて解像度も自動で切り替わります(詳しくは「4.8 画面の向きを変える」)。横ピクセルと縦横比の両方を固定した場合は、回転しても解像度は変わりません。

VNC では解像度は接続先のサーバーが決めるため、この項目は表示されません。

FreeRDP 詳細設定(RDP のみ)

通常は変更不要です。既定から変えた項目だけが保存され、変更があると「変更あり」と表示されます。「既定に戻す」で全項目を初期状態に戻せます。主なカテゴリは次のとおりです。

グラフィクス・コーデックGFX パイプライン、各種コーデック

ネットワーク・再接続自動再接続、タイムアウト、IPv6

自宅の PC でよくある自己署名の証明書は、そのまま受け入れて接続します。

保存

「ラベル」と「ホスト名 / IP」の両方が入力されていると、右上の 保存 が押せるようになります。

4. 接続中の画面

接続すると、接続先の画面が黒い背景の中に表示されます。上のバーには接続先の名前と 3 つのボタンがあります。

ボタン動作
左上の <切断してホスト一覧に戻ります。ロック中の修飾キーは自動で解放されます

4.1 接続中と切断

  • 接続処理中は「接続中… ホスト名:ポート」と表示されます。
  • 接続が切れると「切断されました」と理由が表示され、「再接続」と「閉じる」が選べます。

4.3 入力モード

右上のアイコンをタップするたびに、ダイレクト → トラックパッド → マウス の順に切り替わります。

モード1 本指タップ1 本指ドラッグ2 本指タップ長押し(0.45 秒)
ダイレクト(手のアイコン)触った位置を左クリック触った位置にカーソルが追従触った位置を右クリックその場で左ボタンを押したまま、指の移動でドラッグ&ドロップ
トラックパッド(カーソルのアイコン)現在位置を左クリックノート PC のトラックパッドのようにカーソルが相対移動現在位置を右クリック現在位置で左ボタンを押したまま、相対移動でドラッグ&ドロップ
マウス(マウスのアイコン)何もしないカーソルの相対移動のみ何もしない何もしない
  • ダイレクト はタブレット的に「触った場所を押す」操作、トラックパッド は細かいカーソル操作向きです。
  • マウス モードは、クリックをすべて画面上の L / R ボタン(カスタムキー)で行うモードです。ゲームなど、誤タップでクリックしたくない場面に向いています。
  • 長押しが成立すると端末が短く振動します。画面を拡大中は長押しドラッグは無効です(画面のスクロールが優先されます)。

4.4 共通のジェスチャー

ジェスチャー動作
2 本指で上下にドラッグマウスホイールのスクロール(30pt ごとに 1 ノッチ)

拡大中に 1 本指ドラッグカーソルを動かし、画面の端(外側 22%)に近づくと表示範囲が自動でスクロールします

拡大するほど、指の移動に対するカーソルの動きはゆっくりになり、細かい操作がしやすくなります。

4.5 ミニマップ

画面を拡大しているあいだ、右上に画面全体の縮小図が出て、緑の枠が今見ている範囲を示します。2 秒間操作がないと自動で消え、ズームやスクロールをすると再び表示されます。等倍に戻すと消えます。

4.6 特殊キーバー

メニューの「特殊キーバー」で画面下部に表示します。

  • 上段左の Ctrl / Shift / Alt / 田(Windows キー) はロック式です。タップすると押しっぱなしになり(点灯)、もう一度タップで解放します。ロック中に他のキーやクリックをすると組み合わせになります。画面を離れると自動で解放されます。
  • 上段右でカテゴリを選ぶと、下段にそのカテゴリのキーが横に並びます。タップで 1 回押します。
  • カテゴリ: よく使う / 単独 / 英字 A-Z / 数字 0-9 / 記号 / F1-12 / 矢印 / 編集 C+ / アプリ / Windows

4.7 キーボード入力

画面のキーボード(ソフトキーボード)

  • 右上のキーボードアイコンで表示します。
  • 日本語入力は iOS の変換をそのまま使えます。変換中の文字は端末側で保持され、確定した時点で接続先に送られます。
  • Enter、Tab、Backspace はキーとして送られます。

外付けキーボード(Bluetooth、Magic Keyboard など)

  • つなぐと画面のキーボードは自動で畳まれます。
  • キー入力は iOS の文字変換を通さず、そのまま接続先に送られます。接続先の日本語 IME(Windows の Microsoft IME など)がそのまま使え、変換候補や予測もいつもの環境のままです。
  • Ctrl+C、Alt+Tab、Windows キー、ファンクションキー、テンキー、かな / 英数 / 変換 / 無変換 などの JIS キーに対応しています。
  • キーを押し続けると 0.4 秒後からリピートします。修飾キーはリピートしません。
  • Mac 用キーボードでは既定で ⌘ が Alt、Option が Windows キーとして送られます(メニューの「⌘/Option入替」で変更できます)。

4.8 画面の向きを変える

接続中に端末を回転させると、縦横に合わせて表示が切り替わります。

  • ホストの解像度設定で縦横比が「自動」の場合(既定)、新しい向きに合った解像度を接続先に要求します。Windows 8.1 以降への RDP 接続では接続を保ったまま切り替わり、1〜2 秒ほどで描き直されます。
  • 接続先が解像度の変更に対応していない場合(古い Windows、Mac の画面共有など)は、新しい解像度で自動的に再接続します。数秒間「接続中…」と表示されます。
  • 横ピクセルと縦横比の両方を固定しているホストは、回転しても解像度を変えません。
  • カスタムキーの配置は縦向きと横向きで別々に保存されます。

4.9 クリップボード共有(RDP のみ)

  • 接続したとき、および他のアプリから KnisRDT に戻ってきたときに、iPhone / iPad のクリップボードのテキストが接続先に送られます。
  • 接続先でコピーしたテキストは、iPhone / iPad のクリップボードに自動で入ります。
  • 不要な場合は FreeRDP 詳細設定 → リダイレクト → クリップボード共有 を OFF にします。

4.10 音声(RDP のみ)

接続先の音声が iPhone / iPad で再生されます。本体のサイレントスイッチが ON でも鳴ります。不要な場合は FreeRDP 詳細設定 → 音声 → 音声再生リダイレクト を OFF にします。

5. カスタムキー

画面上の好きな位置に、キーやマウスボタン、十字キーなどを置けます。ゲーム、ターミナル、エディタなど用途ごとに配置を保存して切り替えられます。

5.1 最初に配置されるもの

初めて接続したとき、画面右下に L(左クリック)と R(右クリック)のボタンが自動で置かれます。縦向き・横向きそれぞれで最初に接続したときに配置されます。

5.2 編集モード

  • 入る: メニュー → 「カスタムキーを編集」
  • 出る: 編集バーの「完了」、またはメニュー → 「編集を終了」

編集モード中は画面にグリッド線が出て、キーはグリッドに沿って移動します。キーの枠の色は、通常が黄、選択中が赤、グループに入っているものが水色です。編集中はキー本来の動作は止まります。

5.3 編集バー

編集モード中に表示される浮動バーです。左端の三本線をドラッグするとバー自体を移動でき、位置は記憶されます。

選択選択モードの ON/OFF。ON のあいだキーをタップすると選択・解除できます
完了編集を終えて保存します

選択モードで 1 つ以上選ぶと、2 段目に次の操作が出ます。

6. ウィジェット

十字キー(D-pad)

半透明の円で、8 方向に対応します。

  • 触れた位置が原点になり、そこから指を動かした方向のキーが押しっぱなしになります。方向を変えると押し直します。指を離すと全方向が解放されます。
  • 中心から少し(14pt 未満)の範囲はデッドゾーンで、何も押しません。
  • 「十字キー(矢印)」は矢印キー、「十字キー(テンキー)」はテンキーの 8 / 2 / 4 / 6 を送ります。

スクロールホイール

縦ドラム風の見た目で、指を上下にドラッグすると一定量ごとにホイールが 1 ノッチ動きます。ダブルタップで速度を切り替え(低速 → 高速 → 中速 → 低速)、下端のラベルに現在の速度が出ます。

スクロールスライダー

つまみを中央から上下に動かすと、離した距離に応じた速さで連続スクロールします。指を離すとつまみは中央に戻って止まります。ダブルタップで速度を切り替えられます。

7. データの保存場所と安全性

データ保存先
接続先の設定(ラベル、ホスト、ポート、ユーザー名、解像度、詳細設定)端末内のアプリ用データベース
パスワードiOS キーチェーン。この端末でのみ使える設定で、バックアップから他の端末へは引き継がれません
カスタムキーの配置とプロファイル端末内のアプリ設定
入力モード、カーソル速度、透明度、⌘/Option 入替、スクロール速度端末内のアプリ設定(全接続先で共通)

アプリは接続先との RDP / VNC 通信以外の通信を行わず、解析や広告の仕組みも含んでいません。アプリを削除すると、これらのデータはすべて端末から消えます。

8. こんなときは

症状確認すること
接続できない接続先と同じネットワーク(または VPN)にいるか。接続先でリモートデスクトップ / VNC が有効か。ポート番号が合っているか。iOS の「ローカルネットワーク」の許可が ON か
Windows Home に RDP でつながらないHome はリモートデスクトップのホストになれません。VNC サーバーを入れて VNC で接続してください
外付けキーボードで日本語が打てない接続先(Windows)側で IME を日本語にしてください。KnisRDT は iOS の変換を通さず、接続先の IME で変換します
