よくある質問

接続できません
接続先 PC と同じネットワーク(または VPN)に入っているか、接続先でリモートデスクトップ(RDP は通常 3389 番、VNC は 5900 番)が有効になっているかをご確認ください。 初回接続時に表示される「ローカルネットワーク上のデバイスの検索と接続」の許可が必要です。拒否した場合は「設定 › プライバシーとセキュリティ › ローカルネットワーク」から KnisRDT を有効にしてください。
Windows の Home エディションに接続できますか
Windows Home はリモートデスクトップのホスト機能を備えていません。Pro 以上のエディション、または VNC サーバーをご利用ください。
パスワードはどこに保存されますか
端末内の iOS キーチェーンにのみ保存され、外部には送信されません。詳しくは プライバシーポリシー をご覧ください。
画面上のボタン(カスタムキー)を変更したい
セッション画面のメニューからカスタムキーの追加・移動・削除ができ、配置はプロファイルとして複数保存できます。

Contact

For bug reports, questions, or feature requests, email knishis.dev@gmail.com. Please include your device model, OS version, and the kind of host you connect to.

FAQ

I can't connect
Make sure your device is on the same network (or VPN) as the host and that remote desktop is enabled on the host (RDP usually uses port 3389, VNC port 5900). KnisRDT needs the Local Network permission; enable it in Settings › Privacy & Security › Local Network if you declined the prompt.
Where is my password stored?
Only in the iOS Keychain on your device. It is never sent to the developer or any third party. See the Privacy Policy.
