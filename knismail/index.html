よくある質問

ふだんのパスワードでログインできません
Gmail / iCloud / Yahoo! JAPAN は、各サービスで発行する「アプリ パスワード」(iCloud は「アプリ用パスワード」)を入力します。 Gmail は Google アカウントで 2 段階認証プロセスを有効にしたうえで、アプリ パスワードのページで作成します。
Google のアプリ パスワードのページが「お使いのアカウントでは利用できません」になります
2 段階認証プロセスが無効のとき、会社・学校のアカウントで管理者が禁止しているとき、2 段階認証がセキュリティ キーだけのときは作成できません。 まず 2 段階認証プロセスを有効にしてください。
Outlook / Microsoft 365 は使えますか
現在の版では対応していません(Microsoft のログイン画面を使う方式が必要なため)。
通知は来ますか
来ません。通知の許可を求めず、アイコンのバッジや未読の件数も出しません。アカウントを開いたときにだけ受信します。
開いたメールを未読のままにしたい
設定の「開いたメールを既読にする」をオフにすると、サーバー側は未読のままになります。
HTML メールの画像が表示されません
開封の追跡を防ぐため、画像は自動では読み込みません。本文の上の「読み込む」で、そのメールだけ読み込めます。 設定の「画像を自動で読み込まない」をオフにすると常に読み込みます。
メールやパスワードはどこに保存されますか
パスワードは端末のキーチェーンにだけ保存します。メールは端末に保存せず、開くたびにメールサーバーから取得します。 詳しくは プライバシーポリシー をご覧ください。

FAQ

My usual password does not work
Gmail, iCloud and Yahoo! JAPAN require an app-specific password issued by each service. For Gmail, turn on 2-Step Verification and create one on the App passwords page.
Is Outlook / Microsoft 365 supported?
Not in this version.
Will I get notifications?
No. The app never asks for notification permission and shows no badge or unread counters. Mail is fetched only while an account is open.
Images in HTML mail are not shown
Remote images are blocked by default to prevent open tracking. Tap "読み込む" (Load) above the message, or change the setting.
Where are my mail and passwords stored?
Passwords are stored only in the device keychain. Mail is not stored on the device; it is fetched from your mail server each time. See the Privacy Policy.
